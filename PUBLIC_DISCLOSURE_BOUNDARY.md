# Public Disclosure Boundary

Allowed: synthetic benchmark contracts, public-safe status readbacks, plots,
manifests, hashes, replay requests, pending replay receipts, and checker logic.

Forbidden: production ARIN22 kernel source, protected container build contexts,
credentials, customer/client data, private data-room URLs, hidden adversarial
corpora, RabbitMQ/S3 secrets, and commercial production datasets.

Public wording must keep this boundary:

> Foundation and governed routing validated; production ARIN22 kernel pending.
