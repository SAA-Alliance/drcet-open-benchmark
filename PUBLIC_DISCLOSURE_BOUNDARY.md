# Public Disclosure Boundary

This repository is a public-safe evidence surface. It may publish synthetic fixtures, aggregate status counters, telemetry-readback summaries, and claim-boundary metadata.

Forbidden in this repository: production source, runtime build contexts, credentials, customer/client data, private data-room URLs, hidden adversarial corpora, commercial production datasets, protected factors, construction names, theorem-specific implementation labels, or artifact paths that reveal internal numerical design.

Public wording must stay generic:

> Public-safe synthetic lanes validate release discipline and evidence gating. Internal implementation details and implementation-specific mathematical surfaces are withheld.

Any stronger claim belongs in the private data room, not in this open repository.
