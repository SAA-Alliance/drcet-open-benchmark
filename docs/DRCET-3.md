# DRCET-3: Attribution and Stress Equivalence

DRCET-3 covers attribution and stress surfaces:

- factor attribution;
- stress replay attribution;
- contribution concentration;
- gross/net attribution reconciliation;
- stochastic attribution stream checks.

The draft protocol requires explicit attribution basis and normalization rules. A DRCET-3 packet must disclose whether attribution is additive, normalized, residualized, or withheld.
