# DRCET-4 GitHub Disclosure Boundary

The open repository may contain public-safe summaries for DRCET-4 lanes, but must not expose construction names, protected factors, production source, runtime build contexts, or method-specific implementation breadcrumbs.

Allowed: aggregate counts, release-state discipline, hash readbacks, and public-safe claim boundaries.

Forbidden: internal method names, theorem-specific labels, internal implementation details, protected factors, private data-room URLs, and detailed implementation traces.
