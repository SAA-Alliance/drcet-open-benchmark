## Plain-Language Summary

A deterministic risk engine was checked against Monte Carlo reference runs using 10,000,000 simulated paths per method. The deterministic and Monte Carlo results matched inside pre-declared limits across all reported checks.

## DRCET-2: Path-Functional Equivalence

DRCET-2 checks path-dependent risk measures: terminal loss, max drawdown, time underwater, recovery horizon, and jump count.

Setup:

- 10,000,000 paths per method.
- 120 checks.
- Horizons: 30D, 90D, 180D.
- Model types: empirical bootstrap, Gaussian, Merton jump, Markov regime-switch.
- Execution: CPU-only, no GPU.
- Wall time: approximately 3,706.48 seconds, about 61.8 minutes.

| Measure | Worst gap vs Monte Carlo | Allowed limit | Result |
|---|---:|---:|---|
| Biggest loss level | 1.0 pp | 2.5 pp | PASS |
| Deepest drawdown | 1.0 pp | 2.5 pp | PASS |
| Number of jumps | 0.0017 | 0.35 | PASS |
| Time underwater | 0, exact match | 7 days | PASS |
| Recovery time | 0, exact match | 7 days | PASS |

Result: `120 PASS / 0 WATCH / 0 FAIL`.

## DRCET-3: Attribution and Stress Equivalence

DRCET-3 checks whether the engine explains risk and scenario impacts consistently: factor/stress attribution, stress replay, contribution concentration, and attribution geometry.

Setup:

- 10,000,000 paths per method.
- 60 checks.
- 4 factor profiles.
- 6 stress scenarios.
- 26 factors.
- Execution: CPU-only, no GPU.
- Wall time: approximately 168 seconds.

| Shock scenario replayed | Impact on portfolio | Match vs Monte Carlo |
|---|---:|---|
| US mega-cap technology shock | -18.49% | exact match |
| Communication services de-rating | -7.57% | exact match |
| Technology hardware drawdown | -11.08% | exact match |
| Commodity sleeve shock | -0.81% | exact match |
| Crypto market crash | -0.64% | exact match |
| Settlement sleeve par shock | -0.003% | exact match |

Result: `60 PASS / 0 WATCH / 0 FAIL`.

For stochastic attribution measures, the worst observed gap was `0.025 pp` against a `1.0 pp` limit.
